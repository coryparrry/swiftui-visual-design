# Research starting points

Use these sources to begin visual and component research when the user has not supplied their own references. Recheck live contents, availability, licenses, and compatibility before recommending adoption. The labels below are research angles, not current capability guarantees.

| Source | Research angle |
|---|---|
| [Inspora](https://www.inspora.design) | Visual design references |
| [SwiftUX components](https://swiftux.app/uicomponents) | Source components and interaction patterns |
| [ShipSwift](https://github.com/signerlabs/ShipSwift) | Reusable component library |
| [SwiftUIShaders](https://github.com/krispuckett/SwiftUIShaders) | Shader effects |
| [PopupView](https://github.com/exyte/PopupView) | Overlays and transient feedback |
| [SwiftUI Introspect](https://github.com/siteline/swiftui-introspect) | Native-control access and customization |
| [SwiftUI Animations](https://github.com/Shubham0812/SwiftUI-Animations) | Motion examples |
| [SwiftfulUI](https://github.com/SwiftfulThinking/SwiftfulUI) | Reusable UI component candidate |


Compare candidates against the app’s actual screens or planned user flows and constraints. Inclusion here does not establish a selected dependency, compatibility, or a verified visual improvement.
